Make — moduli koje stvarno koristiš

Make ima tisuće aplikacija i desetke tisuća modula. U praksi devedeset posto scenarija koristi ovih trideset i pet. Uz svaki interni naziv koji vidiš u blueprintu.

01

Kako čitati ovu karticu

Dva naziva za istu stvar

U sučelju Make pokazuje ljudski naziv — Add a Row, Router, Create a Prompt.

U blueprintu, dakle u JSON datoteci, stoji interni naziv — google-sheets:addRow, builtin:BasicRouter, anthropic-claude:createAMessage.

Zato je uz svaki modul ovdje naveden i interni naziv: kad pogledaš u blueprint ili kad ti Make javi grešku, znaš o čemu je reč.

Pet modula nosi većinu posla

  • Watch New Rows — najčešći okidač. Obrazac upiše redak, scenarij krene.
  • Create a Prompt — AI korak. Ovdje živi sistemska uputa.
  • Router — razdvaja postupak po rezultatu.
  • Add a Row — log i arhiva. Ne prepisuje ništa, pa je najsigurniji upis.
  • Create a Draft — sve prema klijentima ide kao nacrt.
Ako naučiš samo ovih pet, možeš sam/sama sagraditi većinu scenarija iz Modula 7 i 8.
02

Moduli

Filtriraj po skupini ili traži po tome što ti treba.

Tok i logika

Router

builtin:BasicRouter

Dijeli tok na više ruta. Svaka ruta ima svoj filtar.

Kada: Kad ista ulazna informacija treba različit postupak — npr. eskalacija DA ili NE.

If-else

builtin:BasicIfElse

Kao Router, ali s uvjetima i mogućnošću spajanja natrag u jedan tok.

Kada: Kad se rute poslije moraju vratiti u zajednički završni korak.

Merge

builtin:BasicMerge

Spaja if-else rute natrag u jedan tok.

Kada: Uz If-else, kad na kraju svi putovi vode u isti korak.

Iterator

builtin:BasicFeeder

Razdvaja niz u pojedinačne pakete koji se obrađuju jedan po jedan.

Kada: Kad iz jednog ulaza dobiješ listu — npr. deset redaka ili pet privitaka.

Array aggregator

builtin:BasicAggregator

Suprotno od Iteratora — spaja više paketa u jedan niz.

Kada: Kad AI korak treba vidjeti sve retke odjednom, a ne jedan po jedan.

Repeater

builtin:BasicRepeater

Pokreće sljedeće module zadani broj puta.

Kada: Rijetko. Najčešće za generiranje niza brojeva ili ponavljanje poziva.

Greške

Resume

builtin:Resume

Preskače grešku i nastavlja s tim paketom.

Kada: Kad korak nije nužan — npr. upis u log koji smije pasti.

Skip

builtin:Ignore

Preskače i odbacuje paket koji je izazvao grešku.

Kada: Kad jedan neispravan zapis ne smije zaustaviti cijeli scenarij.

Retry

builtin:Break

Sprema neuspjeli paket za automatsko ponavljanje ili ručni pregled.

Kada: Za privremene greške — mreža, ograničenje broja poziva.

Commit

builtin:Commit

Zaustavlja scenarij bez obrade ostatka.

Kada: Napredno. Kad nakon greške ništa više ne smije proći.

Rollback

builtin:Rollback

Zaustavlja scenarij s greškom i vraća ACID module.

Kada: Napredno, za scenarije gdje je djelomičan upis gori od nikakvog.

Ulaz i okidači

Custom webhook

gateway:CustomWebHook

Pokreće se kad na adresu dođu podaci. Trenutačno, bez čekanja.

Kada: Kad obrazac, web stranica ili drugi alat mogu poslati podatke sami.

Custom mailhook

gateway:CustomMailHook

Kao webhook, ali okidač je mail poslan na Makeovu adresu.

Kada: Kad alat može poslati mail, a ne zna za webhook.

Webhook response

gateway:WebhookRespond

Vraća odgovor onome tko je pozvao webhook.

Kada: Kad web stranica čeka odgovor — npr. potvrdu prijave.

Watch New Rows

google-sheets:watchRows

Pokreće se kad se pojavi novi redak.

Kada: Najčešći okidač u praksi. Obrazac upisuje u tablicu, scenarij kreće.

Watch Files in a Folder

google-drive:watchFilesInAFolder

Pokreće se kad u mapu dođe nova ili izmijenjena datoteka.

Kada: Transkripti, skenirani dokumenti, izvozi iz drugih sustava.

Watch Emails

email:TriggerNewEmail

Pokreće se na novi mail po zadanim kriterijima.

Kada: Podrška, upiti, dokumenti koji dolaze mailom.

Tablice

Add a Row

google-sheets:addRow

Dodaje redak na kraj tablice.

Kada: Log, arhiva, registar. Najsigurniji upis jer ništa ne prepisuje.

Update a Row

google-sheets:updateRow

Mijenja postojeći redak po broju.

Kada: Kad upisuješ status ili rezultat u redak koji je pokrenuo scenarij.

Search Rows

google-sheets:filterRows

Vraća retke koji odgovaraju kriteriju, s brojem retka.

Kada: Tjedni pregledi, provjera postoji li zapis prije upisa.

Get Range Values

google-sheets:getSheetContent

Vraća sadržaj zadanog raspona.

Kada: Kad ti treba cijeli blok podataka odjednom, npr. cjenik.

Bulk Add Rows

google-sheets:addMultipleRows

Dodaje više redaka odjednom.

Kada: Kad iz jednog ulaza nastane više zapisa — npr. pet zadataka iz sastanka.

AI

Create a Prompt

anthropic-claude:createAMessage

Šalje upit modelu i vraća odgovor. Ovdje ide sistemska uputa.

Kada: Glavni AI korak. Temperatura na 0 za automatizacije.

Upload a File

anthropic-claude:uploadFile

Predaje datoteku modelu za obradu.

Kada: Za analizu dokumenata koje ne želiš pretvarati u tekst.

List Skills

anthropic-claude:listSkills

Vraća popis postavljenih skillova.

Kada: Kad radiš s vlastitim Claude skillovima.

Izlaz

Create a Draft

email:ActionCreateDraft

Sprema poruku kao nacrt u zadanu mapu. Ne šalje.

Kada: Sve što ide klijentu, dok automatizacija ne radi tri mjeseca besprijekorno.

Send an Email

email:ActionSendEmail

Šalje poruku.

Kada: Interne obavijesti i izvještaji sebi. Prema klijentima tek nakon dugog testiranja.

Create a File from Text

google-drive:createAFileFromText

Stvara datoteku iz teksta.

Kada: Kad rezultat treba ostati kao dokument, npr. nacrt članka.

Download a File

google-drive:getAFile

Preuzima sadržaj datoteke.

Kada: Uz okidač na mapu — okidač daje ime, ovaj modul sadržaj.

Pomoćni

Tools

util

Postavljanje varijabli, uvjeti, pretvorbe teksta i datuma.

Kada: Kad treba očistiti vrijednost prije usporedbe ili spojiti nekoliko polja.

JSON

json

Parsiranje i sastavljanje JSON-a.

Kada: Kad AI korak vraća JSON ili kad se šalje podatak vanjskom sustavu.

Text parser

regexp

Izvlačenje dijelova teksta po uzorku.

Kada: Kad iz odgovora treba izvući samo oznaku ili broj.

HTTP

http

Poziv na bilo koju adresu.

Kada: Kad aplikacija nema svoj modul u Makeu.

Data store

datastore

Makeova mala baza za pamćenje između izvođenja.

Kada: Kad scenarij mora znati što je već obradio — sprječava duplikate.
Ništa ne odgovara toj pretrazi.
03

Četiri obrasca koja rješavaju većinu slučajeva

Ocijeni pa razdvoji

watchRows → createAMessage → BasicRouter → dvije rute

Osnova svakog scenarija koji nekako klasificira ulaz — kvalifikacija upita, eskalacija, trijaža.

Skupi pa sažmi

filterRows → BasicAggregator → createAMessage → ActionSendEmail

Za sve periodične preglede. Aggregator je ključan — bez njega AI korak vidi jedan redak po izvođenju.

Razlomi pa obradi svaki

createAMessage → BasicFeeder → addRow

Kad iz jednog sastanka nastane pet zadataka. Iterator ih razdvoji, pa svaki postane redak.

Provjeri pa upiši

filterRows → filtar „ne postoji“ → addRow

Jedina pouzdana obrana od duplikata. Alternativa je Data store, ako izvor nije tablica.

Jedno pravilo o operacijama: svaki modul u svakom izvođenju troši jednu operaciju. Scenarij od šest modula koji se pokreće sto puta mjesečno je šesto operacija. Zato filtar ide odmah iza okidača — sve iza njega troši.
